# Örnek — Privacy & Consent Kit (Kazakhstan)

Қазақ тіліндегі, ешбір қосымша npm пакетсіз жұмыс істейтін cookie таңдауы, құпиялық/келісім/cookie беттері және тіркелу келісімі.

**КҮЙІ: Интеграцияға дайын үлгі, өндірістік заңдық сәйкестікті растамайды.** ChatGPT-та жасалған Örnek сайтының бастапқы коды репозиторийде жоқ болса, бұл файлдар сайтты автоматты түрде өзгертпейді.

## Интеграция

1. Сайт Vite / React / Next.js болса, `public/` ішіндегіні өз жобаңдағы `public/` бумасына көшір. Статикалық сайт болса, осы файлдарды сервер түбіріне орналастыр.
2. Негізгі HTML құжаттың `<head>` бөлігіне мынаны қос:

```html
<link rel="stylesheet" href="/ornek-privacy.css">
<script defer src="/ornek-privacy.js"></script>
```

3. Барлық бетте көрсетілетін төменгі колонтитулға (footer) мынаны қос:

```html
<div data-ornek-privacy-footer></div>
```

4. Тіркелу формасына `data-ornek-consent-form` атрибутын қос (аты, e-mail секілді дербес деректерді жинайтын формалар үшін):

```html
<form data-ornek-consent-form> ... <button type="submit">Тіркелу</button></form>
```

5. Егер Google OAuth тіркелу батырмасы болса:

```html
<div data-ornek-oauth-area>
  <button type="button" data-ornek-oauth-button>Google арқылы тіркелу</button>
</div>
```

React SPA маршрут ауысқанда жаңа DOM пайда болса, тиісті компонент mount болғаннан кейін `window.OrnekPrivacy?.init()` шақыр.

6. Сынақ көрінісі: `integration-example.html` файлын сайттың public-root-ына орналастырып, `/integration-example.html` аш. Бұл демонстрациялық парақ — нақты тіркелу емес.

## Деректерге міндетті талаптар

- Cookie санаттары: **necessary** әрқашан, **analytics/marketing** әдепкіде өшірулі. `window.OrnekPrivacy.getChoice()` — ағымдағы шешім; `onChoice(callback)` — өзгерістерге жауап береді.
- **Өте маңызды:** Google Analytics, Meta Pixel, Yandex Metrika секілді қосымша скрипттерді HTML-ға алдын ала қоспа. Тек келісім `analytics: true` / `marketing: true` болғаннан кейін тиісті кодты жүкте. Consent banner орнату бұрыннан тұрған трекерлерді автоматты түрде бұғаттамайды.
- Пайдаланушы келіспегенде аналитика/маркетинг деректерін сервер жағынан да өңдеме. Келісімді кері қайтарғанда үшінші тарапқа дерек жіберуді тоқтату мен бұрын қойылған optional cookie-лерді жоюды провайдерлер үшін бөлек енгізу керек.
- Тіркелу батырмасындағы checkbox тек клиенттік қорғаныс. **Сервер міндетті түрде** келісімді тексеріп, policy version, timestamp, user id, source бойынша дәлелін (қажет және заңды шектерде) тіркеуі керек. OAuth redirect және API тіркелу кезінде де тексеру қажет.
- Аккаунт/нәтиже/сессияларды жою өтінімі, identity verification, деректерді сақтаудың құқықтық мерзімдері және кәмелетке толмағандарға байланысты рәсімдер backend-те жеке іске асырылуы тиіс.
- Кесте нәтижелері/электрондық пошта/аккаунт және логтар қай серверде сақталатынын нақты анықта; Қазақстан заңының 12-бабындағы оқшау сақтау талабын сақтауға құқықтық және техникалық баға бер. Бұл құжат дерекқордың орналасуын өзгертпейді.
- `public/legal/*.html` беттеріндегі **[ЖАҚШАДАҒЫ ӨРІСТЕРДІ]** толықтыр. Мәтінді қолданыстағы сервистерге сәйкес тексеріп, қажет жерде заңгерлік сараптама жаса. Әзірше `noindex` қойылған.
- Бұл үлгі маркетингтік e-mail келісімін тіркеуді қоспайды; керек болса, дербес opt-in жаса.
- Егер сайттың құпиялық мазмұны өзгерсе, `POLICY_VERSION` жаңарт; ескі cookie шешімдері жаңа нұсқа бойынша қайта сұралады.

## Қауіпсіздік сынағы

1. `localStorage.removeItem('ornek_cookie_consent_v1')` кейін бетті жаңарт: cookie banner шығады.
2. «Міндеттілер ғана» бас: `getChoice().analytics === false`.
3. Footer > «Cookie баптау» арқылы санаттарды өзгертуге болады.
4. Тіркелу формасында құсбелгі жоқ болса, жіберу бөгелуі керек.
5. Құқықтық беттердегі барлық сілтемелер ашылады.
6. Browser Network панелінде келісімге дейін ешқандай analytics/marketing request шықпайтынын тексер.
